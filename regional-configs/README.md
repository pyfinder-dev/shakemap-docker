# Regional native configuration seeds

These directories are image seed sources for the five native configuration
files. Finalization copies only missing profile directories into the selected
runtime's `shakemap/data/regional` area. Existing operator copies are preserved.

A directory name is discoverable before its modules, paths and scientific data
are usable. These seeds are not a claim that every region is ready to calculate.
Do not add fallback rules or scientific substitutions to make them load.

See the [configuration runbook](../docs/configuration.md) for file responsibilities,
container-visible paths, current Italy/Switzerland limitations, supported helpers
and the distinction between service selection and caller recovery.
